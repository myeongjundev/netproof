# NetProof 릴리스 노트 — v1.1.1 (v1.0.0 최종 제출본 포함, 2026-10-24)

네트워크 구성에 대한 AI의 답이나 내 예상을 계산으로 확인하고, 경로·규칙의 근거를 보며 배우는 보안 네트워크 학생용 실습실. 이번 판은 최종 제출본이며, ALEPH 방어전에서 배운 것을 옮겼다([설계](v1-final-design.md)).

- 공개 주소: https://netproof-vert.vercel.app (로그인 없이 학습·실습·침해 가정·판정·정책 검증)
- 소스: https://github.com/myeongjundev/netproof · 태그 `v1.1.1`(최신), `v1.1.0`, `v1.0.0`
- 버전: 웹 앱 1.1.1 · 계산 엔진 0.2.0(판정 의미는 1차 점검 이후 바뀌지 않음)
- 변경 기록: [CHANGELOG.md](../CHANGELOG.md)

## v1.1.0에서 더한 것

- 학습실 수업 도구에 pfSense(들어오는 규칙·첫 일치·기본 차단·상태 추적, 계산하지 않는 별칭·NAT·Floating)
- 침해 가정의 옆 구역 이동 막대(넓은 화면)
- 네트워크 장비 보안 소식: 서버가 CISA KEV 공개 자료 하나만 받아 네트워크·보안 장비 최신 10건을 보인다. v1.1.1부터 로그인 없이 학습실·사례 게시판에서 본다. 설계: [v1.1-design](v1.1-design.md)

## 확인하는 방법 (3단계)

1. 공개 주소 홈에서 "침해 가정 실습 열기"를 눌러 장면 1로 간다.
2. "확인하기" → 피해 범위 `처음 구성 3곳 · 서비스 15개`.
3. 구성 고치기에서 FW em1 규칙을 TCP 10.0.10.10 → 10.0.20.10:3306으로 바꾸고 "고친 구성 확인하기"(휴대폰에서는 "확인하기") → `지금 1곳 · 서비스 1개`. 아래 "수복 기록"에서 `막힘 14 · 아직 닿음 1`과 바꾼 구성을 보고 `.md`로 내려받는다.

## 알려진 한계

- "닿음"은 방화벽과 경로가 막지 않아 연결을 시작할 수 있다는 뜻일 뿐이다. 서비스가 열려 있는지·취약한지는 계산하지 않는다.
- 검사한 서비스와 호스트 쌍만 계산한다. 검사하지 않은 통신은 알 수 없다.
- IPv6·NAT(포트포워딩)·동적 라우팅·VLAN·별칭이 판정에 필요하면 "판정 불가"로 멈춘다.
- ZTNA는 "필요한 앱만 연다"는 네트워크 부분만 계산한다. 사용자·기기 확인은 계산하지 않는다. XDR의 탐지·격리는 NetProof의 범위가 아니다.
- 운영 DB의 저장 사례 재판정은 비밀번호 미확보로 보류 중이다.
- 보안 소식은 서버 인스턴스 메모리에 6시간 저장한다. CISA에 닿지 못하면 이전 자료("오래된 자료" 표시)나 오류를 보이고, 사례 게시판은 그대로 동작한다.
- 보안 소식의 소켓 대기는 5초, 본문은 5MiB로 제한한다. 5초는 전체 처리 시간의 상한이 아니며, 장애 중 재시도 간격과 인스턴스 간 캐시는 후속이다.
