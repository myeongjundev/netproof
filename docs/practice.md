# 실습 과제 추가

`web/src/practice.ts`의 `PRACTICE`에 공개 예시(`/api/examples`)의 `id`와 같은 `case_id`, 제목, 한 줄 질문, 2~4개의 확인할 점을 추가합니다. 네트워크와 흐름은 예시 API에서 가져오므로 템플릿에 복사하지 않습니다. 대응하는 예시가 없으면 과제는 표시되지 않습니다.

질문과 확인할 점에 정답, 판정, 결정 규칙 번호를 쓰지 않습니다. 과제를 시작하면 받은 답은 비어 있으며, 사용자가 직접 판정하고 받은 답이나 자신의 예상을 적습니다. 기존 사례 파일의 `expect`와 손계산 기록은 변경하지 않습니다.

사례의 **복제해 다시 풀기**도 네트워크와 흐름만 편집 초안으로 가져옵니다. 원본은 바뀌지 않으며, 재판정 후 저장한 사례는 현재 사용자가 작성한 별개 사례입니다. 실제 결과와 검토자 확인은 새로 기록해야 합니다. 기존 **판정기에서 열기**는 받은 답까지 유지합니다.

과제 안내는 판정기 화면 안에서만 유지됩니다. 다른 화면으로 이동하면 안내는 사라지고 입력은 남습니다. 공유 링크와 사례 JSON에는 안내나 저장 제목이 포함되지 않습니다.
