# 경로 표시 테스트 응답

`topology-verdicts.json`은 엔진 0.2.0의 `verify(network, flow)`로 얻은 응답 9건이다. `comparison: NO_CLAIM`만 웹 응답 형식에 맞춰 더했다. 기대한 실제 결과나 사람이 정한 `expect`가 아니다. `cases/` 파일은 수정하지 않았다.

처음 3건은 기존 합성 사례 01/02/03의 입력이다. 이후는 메모리에서 그 입력을 복제하여 ACL 전체 허용, 명시적인 stateful 인바운드 허용·기본 차단, 미확인 기본 정책, one-way, 인바운드 방화벽 차단, 중복 장비 id를 만든 UI 시험 입력이다. 실제 장비·운영 사례를 쓰지 않았다.

테스트는 기록된 단계·목적지·원문·버전의 **표시와 재생**을 검증한다. 엔진 응답을 웹에서 다시 계산하지 않는다. 저장된 옛 응답도 표시 대상이므로 fixture를 최신 판정에 맞춰 자동 수정하지 않는다.
